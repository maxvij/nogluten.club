# nogluten.club

Personal recipe website. All recipes are gluten-free and lactose-free.

Built for Max — Senior Product Designer based in Auckland, NZ.
Protein-focused cooking at 75kg bodyweight (target 120–150g/day).

## Stack
- Vanilla HTML/CSS/JS — single `index.html`
- No frameworks, no build steps
- Hosted on GitHub Pages with custom domain

## Structure
- `index.html` — the entire site
- `CLAUDE.md` — context for Claude Code sessions
- `CNAME` — custom domain config

## Categories
- Breakfast
- Lunch
- Dinner
- Snacks / High-protein

## Running locally
Just open `index.html` in a browser. No build step needed.
